# Web Engineer · RAG local

Busca local sobre notas Markdown e PDFs do vault Web Engineer, por terminal,
aplicativo Windows, interface web, API HTTP ou MCP no Codex e no Claude Code.

O projeto recupera trechos com suas fontes; não gera respostas por LLM.
Ao conectar um assistente, ele recebe os trechos e faz a síntese.

## Guia de leitura

1. [Instalação](docs/01.instalacao.md) — preparar o ambiente e criar o índice.
2. [Uso](docs/02.uso.md) — consultar a base e atualizar o índice.
3. [Configuração](docs/03.configuracao.md) — ajustar origem, modelo e trechos.
4. [Codex](docs/04.codex.md) — conectar o assistente à base por MCP.
5. [Claude Code](docs/05.claude-code.md) — conectar pelo WSL.
6. [API HTTP](docs/06.api.md) — integrar consultas em outras aplicações.

7. [Build Windows](docs/07.windows-build.md) — gerar e verificar o executável e o instalador.

Comece pela instalação e pelo uso. Depois, escolha o guia do seu assistente;
Codex e Claude Code são opções independentes.
