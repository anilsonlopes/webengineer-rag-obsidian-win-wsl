# 01 · Instalação

Use o PowerShell na raiz do projeto, fora da pasta sincronizada do Google Drive.
O conteúdo pode continuar no Drive; o ambiente Python e o índice ficam no projeto.

## Preparar o ambiente

```powershell
powershell -ExecutionPolicy Bypass -File scripts\bootstrap.ps1
```

O script cria `.venv`, instala as dependências e baixa o modelo de embeddings.
A instalação precisa de internet. Depois do download, a busca roda localmente.
Se Python não estiver disponível, o script tenta instalá-lo via Scoop ou winget;
sem esses instaladores, instale Python 3.10+ antes de executar o comando.

## Definir o conteúdo

Se ainda não existir `.env`, copie o exemplo:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Edite `WEBRAG_SOURCE_DIR` no `.env` para apontar à pasta de notas e PDFs.
O caminho padrão é `G:\Meu Drive\ContextDirectory\Web Engineer`.
Veja os demais ajustes em [Configuração](03.configuracao.md).

## Criar o primeiro índice

```powershell
.\scripts\rag.ps1 index
.\scripts\rag.ps1 stats
```

Conclua a indexação antes de usar a interface web ou conectar um assistente.
