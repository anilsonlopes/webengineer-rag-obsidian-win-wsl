# 02 · Uso

## Aplicativo Windows

Use **Atualizar índice** após alterar suas notas. **Reconstruir** força uma nova indexação. **Cancelar** preserva o último índice concluído; downloads em andamento terminam antes do cancelamento. As opções avançadas permitem trocar o modelo e ajustar os trechos.

**Abrir busca** abre a interface no navegador. **Abrir logs** ajuda a investigar falhas. O executável `rag.exe`, na pasta de instalação, aceita os mesmos comandos abaixo, inclusive `mcp`, e lê a configuração salva pelo aplicativo.

## Terminal no ambiente de desenvolvimento

Pré-requisito: concluir a [instalação e primeira indexação](01.instalacao.md).
Execute os comandos no PowerShell, na raiz do projeto.

## Consultar pelo terminal

```powershell
.\scripts\rag.ps1 query "como medir Core Web Vitals?"
.\scripts\rag.ps1 query "contraste de cores" -p Acessibilidade --full
.\scripts\rag.ps1 stats
```

`-p` filtra pelo pilar/pasta; use um nome mostrado por `stats`.
`--full` mostra os trechos completos, `-k 3` limita os resultados e
`--json` retorna dados estruturados. A consulta retorna trechos, sem síntese por LLM.

## Abrir a interface web

```powershell
.\scripts\rag.ps1 serve
```

Acesse <http://127.0.0.1:8077>. Para encerrar, pressione `Ctrl+C` no terminal.
Para integrar a busca em outra aplicação, veja [API HTTP](06.api.md).

## Atualizar o conteúdo

Após editar as notas, execute no Windows:

```powershell
.\scripts\rag.ps1 index --rebuild
```

Sem `--rebuild`, `index` compara os arquivos e mantém o índice se nada mudou.
Com `--rebuild`, força a reconstrução, inclusive após mudar modelo ou divisão dos trechos.

Reinicie a interface web/API e os servidores MCP que estiverem em execução:
eles mantêm o índice em memória. No MCP, reinicie a conexão ou a sessão do assistente.
