# 04 · Consumir pelo Codex

Pré-requisitos: Codex CLI disponível e [índice criado no Windows](01.instalacao.md).
O Codex inicia o servidor MCP por **stdio**; não é necessário executar `serve`.

## Conectar no Windows

No PowerShell, registre o servidor usando o caminho absoluto do Python do projeto:

```powershell
codex mcp add web-engineer -- "C:\Users\anils\projects\webengineer-rag\.venv\Scripts\python.exe" -m webrag mcp
codex mcp list
```

Ajuste o caminho se o projeto estiver em outra pasta. O registro fica na
configuração do Codex (`~/.codex/config.toml`). Abra uma nova sessão e use
`/mcp` na CLI para conferir se o servidor está ativo.

## Alternativa: Codex dentro do WSL

No PowerShell, substitua `<name>` pela distribuição em que usa o Codex
(`labafero`, `konton`, `quila` ou `asc`) e prepare o servidor:

```powershell
wsl -d <name> bash /mnt/c/Users/anils/projects/webengineer-rag/scripts/bootstrap-wsl.sh
```

Depois, no terminal dessa mesma distribuição:

```bash
codex mcp add web-engineer -- ~/.local/bin/webrag-mcp
codex mcp list
```

O bootstrap requer `curl` e internet. Para ajustar caminhos, veja
[Configuração](03.configuracao.md#particularidades-do-wsl).
O registro deve ser feito no ambiente do Codex que consumirá a base.
O Windows indexa e o WSL consulta o índice por `/mnt/c`.

## Consultar e verificar

Peça ao Codex:

> Use search_web_engineer para consultar a base sobre Core Web Vitals.
> Resuma as recomendações e cite os arquivos e seções usados.

Confirme a chamada à ferramenta e a presença das fontes na resposta.
As ferramentas disponíveis são:

- `search_web_engineer`: busca trechos por pergunta, quantidade e pilar opcional.
- `read_web_engineer_document`: reúne os trechos indexados de um documento.
- `list_web_engineer_documents`: lista os documentos por pilar.

A recuperação ocorre localmente; os trechos retornados entram no contexto do Codex
para a síntese. Após reindexar, siga a orientação de [reinício](02.uso.md#atualizar-o-conteúdo).

Referência: [documentação oficial de MCP no Codex](https://learn.chatgpt.com/docs/extend/mcp).
