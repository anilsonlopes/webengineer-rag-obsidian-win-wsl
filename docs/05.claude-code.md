# 05 · Consumir pelo Claude Code

Pré-requisitos: Claude Code instalado no WSL, `curl` disponível nessa distribuição
e [índice criado no Windows](01.instalacao.md). Este guia independe da configuração do Codex.

## Preparar o servidor no WSL

No PowerShell, substitua `<name>` pela distribuição em que usa o Claude Code
(`labafero`, `konton`, `quila` ou `asc`):

```powershell
wsl -d <name> bash /mnt/c/Users/anils/projects/webengineer-rag/scripts/bootstrap-wsl.sh
```

O script instala o ambiente e baixa o modelo no WSL, sem `sudo`.
A instalação requer internet.
Ele cria `~/.local/bin/webrag-mcp` e usa o código e o índice existentes em `/mnt/c`.
Para ajustar caminhos, veja [Configuração](03.configuracao.md#particularidades-do-wsl).

## Registrar no Claude Code

Execute no terminal da mesma distribuição escolhida para a instalação:

```bash
claude mcp add web-engineer -s user -- ~/.local/bin/webrag-mcp
```

Abra uma nova sessão do Claude Code para carregar a conexão.
O servidor usa **stdio** e é iniciado pelo assistente; não é necessário executar `serve`.
O Windows acessa o vault e cria o índice; o WSL consulta esse índice sem montar `G:`.

## Consultar e verificar

Peça ao Claude Code:

> Use search_web_engineer para consultar a base sobre contraste de cores.
> Resuma as recomendações e cite os arquivos e seções usados.

Confirme a chamada à ferramenta e a presença das fontes na resposta.
As ferramentas disponíveis são:

- `search_web_engineer`: busca trechos por pergunta, quantidade e pilar opcional.
- `read_web_engineer_document`: reúne os trechos indexados de um documento.
- `list_web_engineer_documents`: lista os documentos por pilar.

A recuperação ocorre localmente; os trechos retornados entram no contexto do
Claude Code para a síntese. Após reindexar, siga a orientação de
[reinício](02.uso.md#atualizar-o-conteúdo).
