# 06 · API HTTP

Pré-requisito: concluir a [instalação e indexação](01.instalacao.md).
No PowerShell, na raiz do projeto, inicie o servidor:

```powershell
.\scripts\rag.ps1 serve
```

O endereço padrão é `http://127.0.0.1:8077`.
Esta API serve a interface web e integrações HTTP; os assistentes usam
o servidor MCP por stdio, descrito nos guias de [Codex](04.codex.md) e
[Claude Code](05.claude-code.md).

## Endpoints

| Método e rota | Resultado |
|---|---|
| `GET /` | Interface web de busca |
| `GET /api/stats` | Metadados do índice |
| `POST /api/search` | Objeto com lista `hits` de trechos encontrados |

## Exemplo de busca

Em outro terminal PowerShell:

```powershell
$body = @{
    question = "Como medir Core Web Vitals?"
    top_k = 6
    pillar = $null
} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8077/api/search" -ContentType "application/json; charset=utf-8" -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
```

`question` é obrigatório; `top_k` e `pillar` são opcionais, com padrões `6` e `null`.
Uma pergunta vazia retorna HTTP 400. Os resultados são trechos, sem síntese por LLM.

Após reindexar, [reinicie o servidor](02.uso.md#atualizar-o-conteúdo).
Para encerrá-lo, pressione `Ctrl+C` no terminal onde executou `serve`.
